# macOS iSCSI Initiator 0.3.2

Подключение iSCSI LUN как диска Finder с чтением и записью. Данные находятся на NAS, полный локальный образ не создаётся. Приложение использует приватный локальный NFS-мост и встроенные дисковые образы macOS; отдельный драйвер и изменение SIP не нужны.

## Возможности

- Discovery, подключение известного Target и выбор номера LUN.
- Чтение/запись реального LUN и SCSI flush.
- Подключение и безопасное извлечение через приложение и строку меню.
- Подготовка ко сну и автоматическое подключение после пробуждения при доступном NAS.
- Спокойное ожидание отсутствующей домашней сети/VPN.
- Сохранение одного профиля; пароль CHAP только в памяти.

## Начать

1. Создайте отдельный тестовый LUN и привяжите его к iSCSI Target на NAS.
2. Скачайте сборку для Apple Silicon или соберите приложение из исходников.
3. Введите свои адрес, порт, Target IQN и номер LUN. При необходимости — односторонний CHAP.
4. Нажмите **Подключить диск**. Пустой LUN можно отформатировать в «Дисковой утилите», существующий совместимый том откроется в Finder.
5. Оставляйте приложение в строке меню; перед намеренным отключением сети извлекайте диск.

Новая установка не содержит адресов реального NAS и сама никуда не подключается. Ранее сохранённый локальный профиль сохраняется при обновлении.

## Ограничения

**Экспериментальная версия, не единственное место хранения важных данных.** Один профиль и один подключённый LUN. Нельзя одновременно монтировать обычный APFS/exFAT LUN с двух компьютеров; приложение не управляет владением между Mac и Windows. Полный обмен exFAT ↔ Windows пока не проверен — реальные проверки выполнены на APFS.

Готовая сборка arm64, подписана ad-hoc, без нотариального заверения Apple. Проверено на M4/macOS 27.0.1/Synology DS220j; другие системы отдельно не проверены. Автоизвлечение перед сном ограничено временем macOS: занятый том или обрыв во время записи могут потребовать ручного восстановления. При неопределённом I/O автопереподключение блокируется, автоматического повтора записи и принудительного извлечения нет.

23 автоматических теста прошли. Проверены сохранность файла после полного переподключения и один настоящий цикл сна/пробуждения. Длительные нагрузки и закрытие крышки во время большой записи не проверялись.

```sh
zsh build-app.sh
swift test
```
